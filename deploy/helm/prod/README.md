# Helm in production

Deploys Cryptomator Hub with bundled Keycloak and PostgreSQL from the published chart, exposed on two public hostnames behind Traefik with a certificate from cert-manager. Passwords not set explicitly are generated by the chart and stored in Kubernetes Secrets.

Requirements: Kubernetes ≥ 1.27 with the Traefik ingress controller (K3s, for example) and a default StorageClass, DNS records for the two hostnames, [cert-manager](https://cert-manager.io/) with a `ClusterIssuer`, `kubectl` and Helm 3.8+.

1. Install the chart with your own values:

   ```bash
   helm install hub oci://ghcr.io/cryptomator/charts/cryptomator-hub --version 2.0.1 \
     --namespace cryptomator --create-namespace \
     --set urls.hub.public=https://hub.example.com \
     --set urls.kc.public=https://kc.example.com \
     --set ingress.controller=traefik \
     --set ingress.certificate.clusterIssuer=letsencrypt
   ```

   | Value | Meaning |
   |---|---|
   | `urls.hub.public` | Public URL of Hub. Baked into Keycloak's realm on **first** start — decide before installing |
   | `urls.kc.public` | Public URL of Keycloak (different hostname or `…/kc` path on the same host) |
   | `ingress.controller` | `traefik` or `nginx` |
   | `ingress.certificate.clusterIssuer` | cert-manager issuer for one certificate covering both hosts; alternatively `ingress.certificate.secretName` for an existing TLS secret, or leave both empty when TLS is terminated in front of the cluster |
   | `hub.admin.password` | Initial password of Hub's `admin` user; generated if unset, must be changed on first login |
   | `keycloak.admin.password` | Password of Keycloak's bootstrap admin `admin`; generated if unset |
   | `hub.secrets.systemClientSecret` | Secret of the `cryptomatorhub-system` client; generated if unset |
   | `postgres.enabled`, `keycloak.enabled` | Set to `false` to use an existing PostgreSQL / Keycloak (see [`../existing-keycloak/`](../existing-keycloak/README.md)) |

   All other values are documented in [`values.yaml`](../../../chart/values.yaml).
2. Wait until all pods are `Running` (`kubectl get pods -n cryptomator -w`), then read the generated passwords:

   ```bash
   kubectl get secret -n cryptomator hub-secrets-hub -o jsonpath='{.data.hub_admin_password}' | base64 -d && echo
   kubectl get secret -n cryptomator hub-secrets-kc -o jsonpath='{.data.kc_admin_password}' | base64 -d && echo
   ```
3. Open `https://hub.example.com` and sign in as `admin`.

For everything else — license, user management, backups, upgrades, Rancher — see <https://docs.cryptomator.org/hub/>.
